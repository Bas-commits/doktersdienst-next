# doktersdienst-next

Web app for **Doktersdienst** — GP out-of-hours / on-call scheduling for Dutch waarneemgroepen, plus **Praktijkplanner** for practice capacity planning.

**New developers:** start with [docs/README.md](docs/README.md).

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3005](http://localhost:3005).

Database and auth setup: [DATABASE_SETUP.md](DATABASE_SETUP.md), [BETTER_AUTH_SETUP.md](BETTER_AUTH_SETUP.md).

```bash
npm test
npm run lint
```
